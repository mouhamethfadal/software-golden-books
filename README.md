# 📚 Software Engineering Must-Read Books

This repository contains a curated list of essential books for software engineers and developers looking to sharpen their
skills.  
Each book is accompanied by a short one-line summary to help you decide what to read next.

Whether you're a beginner or an experienced engineer, these books cover topics such as clean code practices, system design, 
algorithms, microservices, testing, and more.

## 📖 What's Inside

- Clean code principles
- Software design patterns
- System architecture
- Domain-driven design
- Microservices best practices
- Data-intensive applications
- Interview preparation

> Continuous learning is key to becoming a great engineer — happy reading! 🚀
